## Como trabalhamos

- **Ferramentas próprias.** O que usamos para editar e criar, nós mesmos fazemos.
- **Leve e rápido.** Preferimos código simples, sem dependências desnecessárias, rodando na GPU sempre que dá.
- **Gratuito de verdade.** O safelayer editor não tem assinatura, não põe marca d'água e não coleta seus dados.

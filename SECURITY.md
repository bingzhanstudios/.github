# Segurança

Levamos a sério a segurança dos nossos softwares, como o safelayer editor, e de quem os usa.

## Como avisar uma falha

**Não abra uma issue pública.** Avise em particular:

1. No repositório do projeto, use **Security → Report a vulnerability** (quando o repositório tiver essa opção); ou
2. mande uma mensagem direta no X para [@bingzhan_studio](https://x.com/bingzhan_studio).

Conte o que encontrou, como reproduzir e qual versão estava usando. Respondemos o quanto antes e avisamos quando a correção sair.

## Versões com correção

Corrigimos sempre a versão mais recente. O safelayer editor instalado se atualiza sozinho; no portátil e no `.deb`, baixe a versão nova na [página de releases](https://github.com/myangdae/effects-dae-atualizacoes/releases/latest).
